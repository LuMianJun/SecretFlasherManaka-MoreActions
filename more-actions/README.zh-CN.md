# 更多动作使用说明

更多动作可独立使用，也为 MMD 提供环状列表、状态限制、动作音乐、镜头跟随和动作事件。

## 播放

在原版环状列表选择动作。移动、再次选择同一动作、切换原版操作或进入受限状态会停止。通用返回/取消输入不直接结束动作。设置 → 游戏系统中可调整动作音乐音量及面部镜头跟随。

当前正在执行原版允许互切的姿势动作时，会先等自定义动作资源准备好，再通过原版流程退出，待过渡完成后播放。遵循原版切换冷却；等待期间再次选择同一动作可撤销请求，另选动作可替换请求，切换场景会撤销等待。手铐、蹲下、坐下和特殊状态等限制仍有效，不会强制把角色从受限状态拉回待机。

打开菜单本身不会结束动作。原版菜单暂停游戏时，动作、音乐和配套镜头保留进度，关闭后继续；不暂停游戏的菜单则继续播放。插件不将原版通用返回/取消输入解释为停止命令；选择同一动作或调用停止接口可明确结束播放。

支持走位的 MMD 动作会通过原角色控制器移动，碰撞受阻会停止。动作走位不会被当作玩家主动移动取消；停止后角色留在实际到达位置。

## 提前停止的诊断

发生输入、状态、外部位移或走位碰撞等保护性取消时，日志增加一条 `ACTION_CANCEL_DIAGNOSTIC` JSON。`reason` 和 `phase` 标明取消类别与阶段，`inputs` / `ringShortcut` / `moveInput` 记录当时输入；界面屏蔽标志用于区分被菜单消费的输入。

`expected`、`actual`、`delta` 按 `[x,y,z]` 记录世界坐标及三维差值，单位为米。普通外部位移保护仍是三维距离超过 0.02 米；`positionReference` 区分上次接受的玩家位置与走位碰撞时的目标位置，`externalDisplacement` 不把碰撞未到达误报为外部推挤。日志还包含播放秒数与原版状态标志，不逐帧刷屏。

## 导入普通 Unity 动画

将已经适配游戏骨架的 Unity Generic 动画包放入本插件 actions 下的独立文件夹，并添加 名称.action.json，例如：

```json
{
  "id": "clap",
  "displayName": "鼓掌",
  "bundle": "clap.bundle",
  "clipAsset": "clap"
}
```

bundle 为动画包文件名，clipAsset 为包内动画资源名称。音频可用 audioFile 指定外部 WAV，或用 audioAsset 指定包内音频，二者选择其一。普通 .anim 或 FBX 不能直接放入使用，需要准备好匹配骨架的动画包。

如果导入 VMD，请同时安装 MMD 插件，按照其 README.zh-CN.md 放置 motion.vmd 等文件；不需要 Unity 编辑器或先转换动画包。

## 动作事件

可以在现有配置中添加 events、onStart、onFinish 和 onCancel，让动作到指定位置时调用已接入的原版功能。音效、原版脚步以及可选 NPC 围观的全部用法见旁边的 [动作事件说明.zh-CN.md](../shared/动作事件说明.zh-CN.md)，音效名见 原版音效名称.txt。

Unity 动画自带的 OnPlaySe、FootL、FootR 会自动接入。出现不支持的内置事件时，可以配置 `"useClipEvents": false`，改用 JSON 事件。修改配置后重启游戏。

## 原游戏表情叠加（更多动作 0.5.0 / MMD 0.9.0）

游戏设置新增 `[更多动作] 叠加原游戏表情`，默认开启。打开设置保留动作；修改后会在后续姿势采样中使用新设置。开启时在原游戏表情上叠加动作表情，同通道权重相加并限制在 0–100；关闭时仅显示动作表情，未映射到动作的动态表情通道归零。捏脸形状保留，停止/取消后归还原游戏表情，不修改游戏存档。

每个动作 JSON 可设置 `"keepGameExpressions": false` 强制关闭叠加，此时游戏设置开启也无效。省略或为 true 时由游戏设置决定。例如：

```json
{ "keepGameExpressions": false }
```

`writeFaceMorphs: false` 仍表示动作完全不接管表情，此时两种叠加设置均不影响原游戏表情。界面开关保存于更多动作插件配置的 `[Face] KeepGameExpressions`，不重写动作 JSON。JSON 在下次启动导入动作时读取。

## 身体姿势接管（更多动作 0.5.1 / MMD 0.9.1）

MMD 播放时接管动作范围内的身体骨骼位置、旋转和体型缩放基准。原版膝盖、脚趾及视线控制仍更新内部状态，但对已接管骨骼的动态写入被隔离；体型、骨长和鞋跟计算保持。每帧进入原生更新前撤回上一帧姿势，避免局部位置累积；结束、取消和场景销毁时恢复原生姿势及 Animator 的原裁剪模式。头发、裙摆等物理链不接管，移动碰撞和取消规则不变。无需增加 JSON 字段。

## 深屈膝 IK 限制（MMD 0.9.3）

修复游戏生成骨架在深屈膝时进入超过 180 度的反折分支。膝盖限制使用带符号的铰链投影，并考虑绑定姿势已有的弯曲角度；同一旋转的 q 与 -q 保持一致。没有改变移动碰撞、镜头或体型。

## 固定模型表情层（更多动作 0.6.1）

使用原版基础模型预生成的动态表情索引，直接定位 `Body.001`，不遍历角色网格或枚举所有形变。MMD 0.11.1 使用内置标准表情映射登记本动作的通道，沿用叠加、JSON 优先级与结束恢复规则。原生眼位、睫毛等外观索引保持保护。首次校验固定布局，读档重绑引用；未知布局跳过表情并记录日志。没有改变原游戏表情状态机或存档。
