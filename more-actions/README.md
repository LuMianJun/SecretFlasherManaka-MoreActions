# 更多动作

支持 Unity 动画包导入、转盘播放、原动作替换、WAV／MP3 配套音乐及逐动作属性配置。

在游戏设置的管理页选择替换来源，可按资源包批量应用，也可逐个原动作选择。

## 快速开始

1. 按[仓库首页](../README.md#安装)从 Release 安装插件，将 Unity 动画包放入 `BepInEx/plugins/SFMMoreActions/Actions/` 后重启游戏。
2. 进入场景并站立不动，按住数字键 **1–8** 打开转盘，用 **Z / X** 切页，鼠标指向新增动作后松开数字键播放。移动或再次选择同一动作可停止。
3. 替换原版动作时，打开 **设置 → 更多动作 → 管理动作替换**，选择来源、开启总开关，关闭菜单并恢复站立待机后生效。与原版同名的片段出现在此管理页。
4. 音乐、表情和镜头在 **设置 → 更多动作** 中调整。

具体导入示例、转盘快捷操作和替换管理见[完整快速开始](README.zh-CN.md#快速开始)。以上为默认键位。
