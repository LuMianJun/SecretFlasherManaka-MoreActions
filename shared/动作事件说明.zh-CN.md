# 给动作添加事件

动作播放到某个位置时，可以播放原版音效、触发原版脚步，或者让 NPC 靠近围观。不需要重新制作动画；在动作配置里添加事件即可，修改后重启游戏。

MMD 动作在动作文件夹的 **action.json** 中填写；没有这个文件时新建即可。Unity 动画包在原有的 **名称.action.json** 中添加。已有音乐延迟等配置请保留，把新内容合并到同一个 JSON，不能直接用示例覆盖整份配置。

## 在指定时间播放音效

下面会在动作开始后的 0.35 秒和 0.85 秒各播放一次运动鞋脚步声：

```json
{
  "events": [
    {
      "time": 0.35,
      "event": "native.playSe",
      "args": { "type": "FootStepSneaker" }
    },
    {
      "time": 0.85,
      "event": "native.playSe",
      "args": { "type": "FootStepSneaker" }
    }
  ]
}
```

常用音效名：`FootStepSneaker`（运动鞋）、`FootStepHeel`（高跟鞋）、`Barefoot`（赤脚）、`ClothesSound`（衣服声）、`UiDecide`（确认声）。完整名称见旁边的 **原版音效名称.txt**。必须使用原名和大小写，不填写数字；原版资源或播放条件也可能影响能否听到声音。

时间从角色动作开始计算，单位为秒，不能小于 0 或超过角色动作时长。音乐延迟不会改变事件时间。0 表示动作实际开始，不是在点击菜单时提前触发。同一时间的事件按填写顺序执行，掉帧跨过多个时间点时仍会依次执行。

## 播放时让 NPC 围观

需要同时安装 NPC 围观插件：

```json
{
  "onStart": [
    { "event": "npc.spectators" }
  ]
}
```

动作开始时召集符合条件的普通 NPC，正常结束或中途取消时自动释放这次请求，不需要另写停止事件。此事件服从 NPC 插件的“启用”总开关、场景和寻路条件，不要求开启“MMD动作触发”。如果其他动作、手动开关或自动规则也在请求围观，释放这次请求后仍可能继续围观。

也可以把 npc.spectators 放进 events，指定到某个时间才开始围观。

## 使用角色当前鞋子对应的原版脚步

```json
{
  "events": [
    {
      "time": 0.4,
      "event": "native.footstep",
      "args": { "foot": "Left" }
    },
    {
      "time": 0.9,
      "event": "native.footstep",
      "args": { "foot": "Right" }
    }
  ]
}
```

这会使用原版脚步流程，按照鞋子、姿态和地面等条件处理。脚步声音会参与原版声音检测；高跟鞋也会沿用原版相关效果。原版脚步音效有约 0.2 秒的间隔限制，密集事件不保证每次都能听到。

## 全部事件配置参数

| 动作配置参数 | 默认值 | 用途 |
| --- | --- | --- |
| `events` | `[]` | 指定时间点执行的事件列表。 |
| `onStart` | `[]` | 动作实际开始时执行一次。 |
| `onFinish` | `[]` | 动作和配套音乐全部正常结束时执行一次。 |
| `onCancel` | `[]` | 已开始的动作因取消、移动、切换、受限状态或错误中断时执行一次。场景或玩家已失效时会跳过回调，但仍释放临时请求。 |
| `useClipEvents` | `true` | 是否使用 Unity 动画自带事件。对 VMD 无影响。 |

每条 events 支持下面的参数：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `time` | 无，必填 | 相对动作开始的秒数。 |
| `event` | 无，必填 | 下表中的事件名称。 |
| `args` | `{}` | 事件参数；每种事件支持的内容不同。 |
| `repeat` | `"EachLoop"` | 循环动作每轮执行；改为 `"Once"` 则本次播放只执行一次。非循环动作均只执行一次。 |

onStart、onFinish、onCancel 每条只填写 event 和可选 args，不填写 time 或 repeat。正常结束只执行 onFinish，中断只执行 onCancel。动作尚未实际开始就取消时，两者都不会执行。重新播放动作会重新计数。

| 事件名称 | args 参数 | 用途 |
| --- | --- | --- |
| `native.playSe` | `type` 必填，原版音效名称 | 使用原版玩家音效播放方法。 |
| `native.animationSound` | `type` 必填，原版音效名称 | 使用原版动画音效回调；Shiofuki 会沿用原版效果分支，其他类型播放音效。通常使用 native.playSe 即可。 |
| `native.footstep` | 见下表，均可省略 | 使用原版脚步回调。 |
| `npc.spectators` | 不需要参数 | 建立本次动作的围观请求，停止时自动释放。 |

native.footstep 的 args：

| 参数 | 默认值 | 可填写的内容 |
| --- | --- | --- |
| `foot` | `"Left"` | `"Left"` 或 `"Right"`。 |
| `seType` | `"FootStepHeel"` | 原版音效名，主要供原版高跟鞋分支使用。实际声音仍服从原版鞋子与姿态规则。 |
| `direction` | `"Forward"` | `Forward`、`Back`、`Left`、`Right`、`ForwardLeft`、`ForwardRight`、`BackLeft`、`BackRight`。用于原版侧移动作的方向匹配。 |
| `isMoveAction` | `false` | 该脚步记录是否用于原版移动动作。普通站立自定义动作保持默认即可。 |

事件名、args 内的参数名和枚举文字请按说明填写大小写。不要写 null、注释或重复参数。当前每个事件列表最多 4096 条；循环同一事件重新触发时，会先释放它上次建立的临时请求。

## Unity 动画自带事件

Unity 动画包内已写入的 OnPlaySe、FootL、FootR 会自动接入实际玩家。OnPlaySe 使用动画的整数音效参数；FootL、FootR 需要原版 MFootAnimationEventRecord 对象。内置事件和 JSON 事件会一起执行；同一时间先执行 JSON 中的事件，不要重复填写相同效果。

出现不支持的内置事件，或不想使用原有事件时，在动作配置中添加：

```json
{
  "useClipEvents": false
}
```

之后可以改用 JSON 定义所需事件。导入普通动画或 VMD 均不需要事件，不配置就保持原有播放方式。

## 常见问题

- **加事件后不能播放：** 检查事件名称和参数；npc.spectators 需要 NPC 围观插件。播放前会检查所有事件，问题会显示在游戏提示和 BepInEx 日志中。
- **正常播放没有声音：** 检查游戏音量、事件时间和音效名称；脚步还受原版间隔和场景条件限制。
- **取消后没有执行结束事件：** onFinish 只在正常结束执行；中断使用 onCancel。围观等临时请求始终由插件自动清理。
- **想调用其他原版方法：** 目前支持的事件以本说明为准，不能直接填写任意 C# 方法名。新增适配器后，才可以通过对应事件名调用。
