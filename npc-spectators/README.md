# SFM NPC Spectators 1.0.0

独立的 BepInEx 6 IL2CPP 插件，输出 `SFM.NpcSpectators.dll`。
不修改游戏源码，不依赖 MMD 插件，不加载动画包，不写原版存档。

## 使用

将 DLL 放入 `BepInEx/plugins/SFMNpcSpectators/`。
配置由首次加载生成于 `BepInEx/config/local.sfm.npcspectators.cfg`。

| 安装组合 | 行为 |
| --- | --- |
| 仅围观插件 | 原版设置页手动召集；配置的原版动作也会触发 |
| 同时安装更多动作和 MMD | 配置的 MMD 动作自动触发围观，结束时释放 |

原版“设置 → 游戏系统”下提供启用、手动召集、原版动作触发、MMD动作触发、所有MMD动作、围观半径和间距。没有插件自定义快捷键。手动召集关闭设置后生效；关闭它不取消其他自动来源，关闭“启用”会释放围观。
移动或取消会结束手动触发。MMD 的停止条件仍由 MMD 插件处理。

默认原版触发为 `HipShake`（原版 ActionType 50002）。
可以将 `Triggers/NativeActions` 设为空，关闭原版动作触发；或填写逗号分隔的枚举名/数字，例如 `HipShake,Dogeza`。
`None/-1` 不可配置为触发动作。插件不会解锁原版动作。

`Integration/FollowMmd` 默认 true；`MmdActions` 默认 `wavefile`。
没有可选播放接口或未安装 MMD 时，围观插件仍可独立运行。MMD 插件提供此接口。
`Integration/FollowAllMmd` 默认 false，保持现有动作名单；开启后所有导入的 MMD 动作均可触发。`Triggers/FollowNativeActions` 默认 true。`Gathering/Radius` 默认 2.8 米，`Spacing` 默认 1.1 米；可在设置页或配置文件调整。

## 动作事件触发

安装更多动作后，可以在动作配置的 onStart 或 events 中添加 `{"event":"npc.spectators"}`（events 内还需 time）。不需要开启 MMD 动作触发，但仍服从“启用”总开关和原版场景条件。每次播放持有自己的请求，停止时自动释放，不影响其他来源。

## NPC 范围与恢复

从原版 `NpcManager.ExistNpcList` 招募当前场景已生成的普通行人，无额外距离过滤。
只接管 FixedType=None、Idle、非警察、未坐下、没有交互令牌且有有效寻路代理和巡逻路线的 NPC。
不招募警察、固定店员、固定坐着/聊天的人、睡眠或正在交互/受惊/发现玩家的 NPC。
符合条件的新生成行人也会加入。每 0.25 秒最多处理 4 次招募，远处行人需要实际走过来。

按多圈分配位置，优先内圈及离 NPC 较近的空位。选点时从玩家腰部、胸口高度向候选点检查场景遮挡，遇到墙或柱子便排除该方向的对应站位；玩家、NPC、触发器不作为遮挡。NavMesh 投影后的实际站位还会复查遮挡，再检查目标楼层、完整路径和已分配位置间距。遮挡结果只在当次招募扫描内复用，后续扫描会重新查询。
障碍物可能导致部分行人无可达围观位置；每 5 秒重试，不传送、不穿墙强拉、不额外生成 NPC。
赶路调用原版 `NpcLocomotion.SimpleUpdateFromOtherState`，围观只提供临时导航目标，保留原版转向、移动、导航同步、FixedUpdate 和近距离碰撞修正。移动速度、帧步长与导航代理同步由原版处理。原版巡逻入口在接管期间暂停，避免覆盖围观目标；不新增卡住计时、重寻路监测或传送。
同一轮围观的中心固定在触发时的玩家位置；MMD 走位不会释放 NPC、重建站位或重新下发目标。后来加入的行人也使用本轮固定中心。到位后停止走路并转向玩家当前位置；这里没有额外欢呼/鼓掌动画。触发结束、取消或场景变化仍按原规则释放，下一轮再取新的中心。

停止时恢复原寻路目标、目标缓存、停止状态和步行动画速度；代理的位置/旋转更新标志不由插件改动。
巡逻路线和路线索引在围观期间不推进。先释放接管，再让原版状态进入逻辑接手。
原版视野、可疑度、发现玩家、任务判定和时间停止仍生效；围观不会屏蔽这些规则。
打开其他 UI 会结束当前接管，设置页手动请求保留至关闭界面后执行；退出场景、失去玩家或游戏结束会结束手动请求及接管。

## 升级兼容

从 Seleka2 前缀版本升级时，请运行安装脚本，迁移配置并备份移走旧 DLL。手动升级需先移走旧 DLL，避免两套围观插件同时加载。

## 常见问题

- **没有人过来：** 检查总开关及触发设置，附近需要有符合条件的普通行人。墙壁、楼层和导航路径可能导致没有合适的站位。
- **玩家走位后 NPC 没有重新聚拢：** 一轮围观使用触发时的固定中心；结束后重新触发，才会以新位置分配站位。
- **打开菜单后散开：** 打开其他界面会结束当前接管；设置页的手动请求会在关闭界面后执行。

反馈问题时请附 `BepInEx/LogOutput.log`，并说明围观触发方式、场景与 NPC 表现。
