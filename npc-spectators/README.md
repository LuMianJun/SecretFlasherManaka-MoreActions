# SFM NPC Spectators 1.0.0

简体中文 | [English](README.en.md)

为 BepInEx 6 IL2CPP 提供可独立安装的 NPC 围观功能，DLL 为 `SFM.NpcSpectators.dll`。
插件调度当前场景里的 NPC，动画播放由对应动作模块负责；单独安装时使用原版动作或手动触发。游戏源码与原版存档保持原样。

## 快速开始

### 可以做什么

- 在设置里手动召集当前场景的普通行人。
- 执行指定原版动作时自动召集，默认由原版摇臀动作触发。
- 配合更多动作和 MMD，在播放 MMD 时自动召集。

NPC 会按游戏导航走到玩家周围，站定后面向玩家。墙壁、楼层、路线和 NPC 状态会影响能否到场。

### 安装

按[仓库首页](../README.md#安装)从 Release 安装 NPC 围观插件，DLL 位于 `BepInEx/plugins/SFMNpcSpectators/`。

| 安装组合 | 行为 |
| --- | --- |
| 仅围观插件 | 原版设置页手动召集；配置的原版动作也会触发 |
| 同时安装更多动作和 MMD | 配置的 MMD 动作自动触发围观，结束时释放 |

### 手动召集

1. 进入有普通行人的场景，站到希望他们聚集的位置。
2. 打开 **设置 → 游戏系统**，找到带 **[NPC围观]** 前缀的选项，确认“启用”已开启。
3. 开启 **手动召集**，按需调整半径和间距。
4. 关闭设置，行人便会开始走近。远处的行人需要时间到场。

### 随动作自动召集

- **原版动作：** 在同一设置页开启 **原版动作触发**，关闭设置后执行原版摇臀动作即可触发。
- **MMD 动作：** 安装更多动作和 MMD，在同一设置页开启 **MMD动作触发** 和 **所有MMD动作**，关闭设置后从转盘播放 MMD。关闭“所有MMD动作”时，仅名单内的动作触发，默认是 WAVEFILE。

### 解散与重新聚集

手动召集后，移动或取消会结束该次手动召集；也可在设置里关闭“手动召集”。由动作触发的围观随对应动作结束而释放。不同来源分别管理，关闭“启用”总开关可释放全部围观。

一轮围观以触发时的位置为固定中心，玩家走位时行人保留已有目标。希望他们到新位置聚集时，先结束本轮，再重新触发。

打开其他界面会结束当前围观，设置页的手动请求会在关闭界面后执行。切换场景也会结束当前围观。

## 高级使用

### 触发配置说明

配置由首次加载生成于 `BepInEx/config/local.sfm.npcspectators.cfg`。

默认原版触发为 `HipShake`（原版 ActionType 50002）。
可以将 `Triggers/NativeActions` 设为空，关闭原版动作触发；或填写逗号分隔的枚举名/数字，例如 `HipShake,Dogeza`。
触发名单使用实际原版动作，排除 `None/-1`；角色可执行的动作仍由原版解锁进度决定。

`Integration/FollowMmd` 默认 true；`MmdActions` 默认 `wavefile`。
MMD 插件通过可选播放接口提供动作状态，独立使用时保留手动召集与原版动作触发。
`Integration/FollowAllMmd` 默认 false，保持现有动作名单；开启后所有导入的 MMD 动作均可触发。`Triggers/FollowNativeActions` 默认 true。`Gathering/Radius` 默认 2.8 米，`Spacing` 默认 1.1 米；可在设置页或配置文件调整。

### 全部插件配置

配置保存在 BepInEx/config/local.sfm.npcspectators.cfg，界面中的开关和滑条可直接修改。手工编辑配置文件后重启游戏即可生效。

| 配置项 | 默认值 | 含义与范围 |
| --- | --- | --- |
| `[General] Enabled` | true | 围观总开关；关闭后释放当前接管。 |
| `[Triggers] FollowNativeActions` | true | 是否由名单中的原版动作自动触发。 |
| `[Triggers] NativeActions` | HipShake | 逗号分隔的原版 ActionType 枚举名或数字；空字符串关闭名单触发，不能填写 None/-1。 |
| `[Integration] FollowMmd` | true | 是否监听 MMD 播放触发围观；未安装 MMD 时不影响其他触发方式。 |
| `[Integration] FollowAllMmd` | false | 开启后所有 MMD 动作均可触发，忽略名单；仍需要 FollowMmd=true。 |
| `[Integration] MmdActions` | wavefile | 逗号分隔的 MMD 动作 ID；仅在 FollowMmd=true 且 FollowAllMmd=false 时使用。 |
| `[Gathering] Radius` | 2.8 米 | 第一圈站位距本轮聚集中心的距离；限制在 1.8～8 米。 |
| `[Gathering] Spacing` | 1.1 米 | 目标站位间的最小间距；限制在 0.8～3 米。 |

“手动召集”默认为关闭，仅保留在当前场景。动作 JSON 的 npc.spectators 事件是另一种可选触发方式，见下节。

### 动作事件触发

安装更多动作后，在动作配置的 onStart 或 events 中添加 `{"event":"npc.spectators"}`，events 内另需 time。事件由“启用”总开关和原版场景条件控制，与“MMD动作触发”开关独立。每次播放各持有一个请求，停止时只释放该请求。

### NPC 范围与恢复

从原版 `NpcManager.ExistNpcList` 中筛选当前场景已生成的普通行人，筛选覆盖整份名单。
招募要求为 FixedType=None、Idle、非警察、未坐下、没有交互令牌，并具有有效寻路代理和巡逻路线。
警察、固定店员、固定坐着或聊天的人，以及睡眠、交互、受惊或发现玩家的 NPC 保持原版行为。
符合条件的新生成行人也会加入。每 0.25 秒最多处理 4 次招募，远处行人需要实际走过来。

按多圈分配位置，优先内圈及离 NPC 较近的空位。选点时从玩家腰部、胸口高度向候选点检查场景遮挡，遇到墙或柱子便排除该方向的对应站位；玩家、NPC、触发器不作为遮挡。NavMesh 投影后的实际站位还会复查遮挡，再检查目标楼层、完整路径和已分配位置间距。遮挡结果只在当次招募扫描内复用，后续扫描会重新查询。
障碍物可能使部分行人找不到可达站位，插件每 5 秒重试。围观使用场景中已有的行人，他们按导航实际走近，位置和碰撞遵循原版规则。
赶路通过原版 `NpcLocomotion.SimpleUpdateFromOtherState` 执行，插件提供临时导航目标。转向、移动速度、帧步长、导航同步、FixedUpdate 和近距离碰撞修正均由原版处理，接管期间暂停原版巡逻入口。赶路沿用这套流程，插件不另设卡住计时、重寻路监测或传送处理。
一轮围观以触发时的玩家位置为固定中心，后来加入的行人也使用该中心。MMD 走位期间，NPC 保留已有接管、站位和导航目标。到位后的表现是站立并面向玩家当前位置；额外欢呼或鼓掌动画暂不提供。触发结束、取消或场景变化时释放接管，下一轮使用新的中心。

停止时恢复原寻路目标、目标缓存、停止状态和步行动画速度，导航代理的位置与旋转更新标志沿用原版。
围观期间保留原巡逻路线与索引，先释放接管，再由原版状态进入逻辑接手。
围观期间继续执行原版视野、可疑度、发现玩家、任务判定和时间停止规则。
打开其他 UI 会结束当前接管，设置页手动请求保留至关闭界面后执行；退出场景、失去玩家或游戏结束会结束手动请求及接管。

### 升级兼容

从 Seleka2 前缀版本升级时，请运行安装脚本，迁移配置并备份移走旧 DLL。手动升级需先移走旧 DLL，避免两套围观插件同时加载。

### 常见问题

- **没有人过来：** 检查总开关及触发设置，附近需要有符合条件的普通行人。墙壁、楼层和导航路径可能导致没有合适的站位。
- **玩家走位后 NPC 没有重新聚拢：** 一轮围观使用触发时的固定中心；结束后重新触发，才会以新位置分配站位。
- **打开菜单后散开：** 打开其他界面会结束当前接管；设置页的手动请求会在关闭界面后执行。

反馈问题时请附 `BepInEx/LogOutput.log`，并说明围观触发方式、场景与 NPC 表现。
