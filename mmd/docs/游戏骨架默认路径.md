# 游戏骨架生成的 MMD 参考姿势（0.10.0）

所有动作统一从玩家网格的绑定姿势生成虚拟 MMD 骨架。保留实际游戏骨长、有效世界尺度和已有的动作/音乐/镜头默认规则，不读取额外模型。

## 数据与求解

- 从网格 bind poses 读取相对于角色根节点的中立参考，不把当前待机姿势当作基准；角色根及祖先的有效缩放进入参考尺寸。原生体型包装节点参与形状识别，不保证任意自定义比例都能精确还原原动作。
- 49 个目标身体骨确定躯干、四肢和手指。Toe 有绑定姿势时才生成脚趾控制；缺少必要骨骼、非法坐标或零长度腿时明确拒绝。
- 生成全亲、中心、槽、腰、上半身 1/2/3、肩 P/C、腕扭转及脚部 IK 控制层级。此层级是实现假设，不是从 VMD 恢复出的作者模型。
- 默认 A-pose 参考 UnityVMDPlayer：左右上臂镜像下垂约 30°，前臂/手腕/手指随参考骨段调整方向。动作 JSON 可写 `"referencePose": "T"` 保留原游戏绑定参考；省略或写 `"A"` 使用默认。虚拟骨架校准后映射回实际骨骼轴，不改变玩家网格绑定数据。
- 参考位置以每 MMD 单位 0.08 个游戏单位转换。水平根位移接入原角色控制器，竖直分量应用于髋部；碰撞、取消和镜头规则见 [根位移与角色控制器](根位移与角色控制器.md)。
- 每次播放独立保有姿势恢复状态，停止/取消后归还原生控制。头发、裙摆等附属物理不由该虚拟骨架接管。

## 预热与缓存

游戏侧只捕获引用和中立数据；后台生成受管参考几何，Unity 辅助对象按帧分步构建。A/T 分别预热与缓存，同体型读档可以重绑定复用。已有体型形状判断及并发租用隔离保持。

## 模型路径迁移

0.10.0 移除 `modelFile`、PMD 解析器、模型自动发现、模型模板缓存及历史配套路径测试。已有 `source.pmd` 文件不再读取；JSON 中的 `modelFile` 请删除，否则明确拒绝导入该动作。安装器不删除用户模型文件。

## 验证边界

SkeletonValidation 链接生产解析器、拓扑生成器、异步准备泵及重定向器，覆盖单位、非法输入、A/T 校准、骨长不变、缓存复用、遮罩和停止恢复。离线场景替身不能代替实际渲染、碰撞和原生派发验收。精确合掌、牵手、摸脸及特殊骨骼仍可能与作者模型存在差异；当前不增加自动接触适配。
