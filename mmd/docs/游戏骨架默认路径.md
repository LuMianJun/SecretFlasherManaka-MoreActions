# 游戏骨架与 MMD 参考姿势

MMD 插件 1.4.12 从玩家网格的绑定姿势构建隐藏采样骨架，在这套原生骨轴上运行固定版本的 UnityVMDPlayer 身体求解。角色骨架和模型由游戏提供，无需附加 PMD/PMX。

## 数据与求解

- `body-bones.json` 是固定身体路径的唯一清单，共 80 条路径，其中 49 条必需。快照只绑定当前角色实际存在且具有身体网格绑定数据的子集，不扫描附属网格来扩充骨架。
- 中立位置和旋转来自固定身体网格的 bind poses，不使用当前待机姿势。实际根尺度进入参考几何；大小腿和胸部长度因子、原生 `PlayerBoneScaleAdjuster` 倒数包装节点进入尺寸及缓存识别。颈部、肩宽、腿间距等原生位置调整尚未完整纳入。
- `GameHumanoidMap` 将原生路径映射到 Unity Humanoid，标准身体轨道采用上游关系，例如 Spine→上半身、Chest→上半身2、Foot→足首。共享 JSON 的 Source/Fallback 字段不替代标准身体映射；附加层用它们和唯一原生名称匹配可用辅助轨道。
- 默认 A 参考沿用 UnityVMDPlayer：恢复初始姿势后，左右上臂绕角色 forward 镜像转动 30°。动作 JSON 写 `"referencePose": "T"` 可保留游戏绑定参考；省略或写 `"A"` 使用默认。调整只作用于隐藏树，不修改玩家网格的绑定数据。
- 读取到的动作经一次 x/z 方向转换后交给上游 Reader。独立输入层清除骨名首个 NUL 后的尾部内容，并保留全半角/常用拼写兼容；身体算法不因此改变。位移沿用 `0.08f` 系数，并在角色实际尺度下求解。隐藏 proxy 与 Armature 使用单位 TRS，测得的米制点位和原生世界骨轴保留在子骨中，避免将原 Armature 的 -90° 再带进上游控制空间。输出使用这套原生骨轴，不追加旧 neutral 校准。
- Toe 有绑定数据时参与脚尖 IK；缺少 Toe 时跳过该侧脚尖控制。动作明确含某侧親指０时，附加层按 0/1/2 驱动该侧三节拇指；否则保持标准上游映射。
- 采样树容纳公共 80 路径：78 根网格 bind 骨和两个 identity 的 BreastRotate 中间父级。51 个标准 Humanoid 输出只是标准主体，不是全部支持上限。
- 附加层按实际轨道支持独立眼与両目、四条腕／手捩及原生辅助骨、腰／取消、肩 P/C、上半身3、D／EX，以及清单内可唯一匹配的原生骨。写回服从范围和路径遮罩；可选原生骨使用当前基线上的增量，不把绑定尺度覆盖到玩家。
- 腰、肩、上半身3与拇指处理先于原足／趾 IK；D／EX 后置作用于变形输出，不反馈 IK。没有附加轨道时保留标准求解数学及调用顺序。只有前置扩展的动作也可按扩展自身末帧求值。
- 水平根位移交给角色控制器，竖直分量相对参考髋高写回；详细规则见[根位移与角色控制器](根位移与角色控制器.md)。停止或取消后，姿势租约归还受控身体骨和表情；头发、裙摆等附属物理继续由游戏处理。

## 预热与缓存

游戏角色初始化完成并稳定后，准备器分帧捕获引用、绑定数据和体型快照，再分步构建隐藏 Unity 树。文件读取及动作包解析仍可在后台完成，隐藏骨架的 Unity 对象在主线程创建。

A/T 参考分别缓存。相同布局、绑定数据、有效尺度和已纳入的体型参数可以复用采样树，角色移动、转向或同体型重载只需重绑定引用。每次播放持有独立的求解状态及原生恢复状态；并发消费者使用不同的可变采样树。

体型通知请求重新准备；新快照形状未变时保留已有树，形状变化并发布新树后使旧播放失效，由公共播放流程退出并归还控制。该流程不做逐帧全骨架或网格测量，也不依赖运行时生成的骨骼清单文件。

## 模型路径迁移

`modelFile` 已移除。已有 `source.pmd` 不再读取；动作 JSON 如仍有 `modelFile`，请删除该字段，否则导入会明确报错。安装器保留用户已有模型文件。

`body-bones.json` 仍是插件所需的共享路径资源。它保存路径清单，绑定矩阵和当前体型由游戏角色提供，二者用途不同。

## 验证边界

`UpstreamValidation` 将移植求解器与固定版本的原始播放器对照；`CompatibilityValidation` 核对原生骨轴、身高与大小腿比例、根位移归属、缓存、遮罩和停止恢复；附加轨道另核对眼／捩、腰肩躯干、D／EX、拇指编号及原生增量。完整范围见[UnityVMDPlayer 功能对照](UnityVMDPlayer功能对照.md)。

离线回归使用 Unity 数学与场景替身，不代表全部原生体型参数已支持，也不能替代游戏内的蒙皮、碰撞和原生派发检查。精确合掌、牵手、摸脸、坐地及脚面接触仍受当前角色和动作作者模型差异影响；试验性接地仅对有匹配接触计划的支撑手脚生效。
