# 根位移与角色控制器

MMD 插件 1.4.11 使用固定版本 UnityVMDPlayer 的完整身体结果提取位移，由更多动作的公共运行时推动游戏角色控制器。固定源码及许可见根目录 `THIRD_PARTY_NOTICES.md`。

## 采样与归属

- 采样树求解全亲、中心、槽、腰及上下半身后，播放层读取隐藏髋点。竖直写回以 Avatar 根为基准，水平走位交给角色控制器。
- 上游位移系数为 `0.08f`，采样树保留角色实际尺度。输出已经处于游戏世界尺度，不再乘旧的源骨长换算比；镜头仍由独立的 `camera.scale` 控制。
- 水平 X/Z 以第零帧的采样髋位置为原点，经开播朝向变换为 `RootDisplacement`。循环位移为支持轨道末端与零帧之差，公共运行时按完整周期累计，避免每轮回到起点。
- `RuntimeVmdPose.Apply` 只输出位移值和身体姿势，不移动角色或模型根。水平移动只通过现有 `PlayerClassAccessor.CharacterController.Move` 应用，不在蒙皮髋部重复写入，也不开启 `Animator.applyRootMotion`。
- MMD 接管髋位移时，水平髋锚点取开播时相对 Avatar 的位置，髋高取动作采样值。两者随当前 Avatar 的位置与朝向变换，原生待机髋的摆动不叠加到整身。其他受控骨按采样树中相对髋的位置写回，旋转使用当前角色朝向乘采样世界旋转。
- 控制器的竖直位置仍由原生重力、地形及碰撞处理。MMD 的根旋转由骨架姿势表达，不另外旋转控制器；这也不是角色跳跃控制器。
- `writeHipTranslation=true` 且动作范围包含髋部时启用位置交接。显式设为 false，或遮罩/骨骼过滤不包含髋部时，不申请 MMD 控制器位移。

公共运行时每帧的绝对水平目标为“开播位置 + 当前位移 + 已完成循环数 × 周期位移”，移动量为目标减去角色实际位置。重复采样同一时刻不会重复累计距离。

固定上游在达到最后支持帧时不再求解。为取得循环累计所需的完整末端，游戏适配层单独执行最后有效整数区间的原 n/n+1 求解，再以原局部 Lerp 的 rate=1 读取末端，随后重置采样状态。这个入口只用于周期预采样，不改变正常逐帧求解的结束条件。

## 碰撞和取消

- 控制器移动拆成最多 0.1 m 的扫掠步，每次姿势输出最多 128 步。非有限值或超过 12.8 m 的单次轨迹断点会停止动作，不转为传送。
- 每步及最终水平目标核对实际到达位置；误差超过 0.02 m 时视为受阻并停止。碰撞保持启用。
- 自己的控制器移动会更新预期位置。玩家移动输入、取消、其他原生动作/状态、外部位置变化、UI、场景和角色更换继续按公共播放规则处理。
- 停止时恢复受控身体骨、髋部和表情，玩家留在碰撞允许的实际到达位置，不返回开播点。未实现根位移接口的普通 Unity 动作保留既有行为。

控制器只约束角色整体位移。试验性接地 IK 在走位后处理计划中的支撑手脚，四肢仍可能穿入墙面。

## 镜头

使用原生跟随镜头播放含根位移的动作时，先完成本帧的角色控制器移动，再按原顺序执行已经暂缓的第三人称、第一人称和主镜头更新。镜头输入和碰撞由原生控制器计算。

镜头沿用独立比例和开播时固定的位置/朝向锚点。循环时只按角色相同的完整周期位移展开原镜头轨迹，单次播放的周期偏移为零；不加入逐帧玩家跟随、省略位移补偿或手部对焦。

归还原生镜头时，将开播前的相对视图恢复到角色已经到达的位置。这只处理退出后的原生视图，不改变正在播放的 VMD 镜头轨迹。

## 验证边界

`CompatibilityValidation` 比较上游采样髋轨迹与游戏侧输出，检查首帧 Y、绝对水平位移、循环位移、重复采样和根节点所有权。公共运行时的离线事件/播放回归覆盖分步移动、受阻、取消、外部移动及镜头恢复。

离线场景和模拟控制器不能代替游戏中的墙体、台阶、斜坡、原生重力或最终蒙皮检查；也不能证明尚未纳入参考几何的颈部、肩宽、腿间距等体型参数已经适配。
