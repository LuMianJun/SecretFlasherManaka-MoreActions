# 根位移与角色控制器（MMD 0.8.0 / 更多动作 0.4.0）

本批参考 UnityVMDPlayer 的中心/槽/全亲位移处理，保留现有虚拟 MMD 骨架与求解器。出处、固定版本和许可见根目录 THIRD_PARTY_NOTICES.md。既有 180° Y 坐标方向参考继续保留。

## 采样与归属

- VMD 的全亲、中心、槽、腰等父层级先由当前求解器合成，再提取下半身/髋部参考相对第零帧的世界向位移，避免只读中心轨道漏掉父级贡献。
- 游戏生成骨架采用 0.08 单位，与默认镜头一致。0.10.0 起统一使用此路径；镜头比例仍可由 camera.scale 独立配置。
- 水平 X/Z 只通过现有 PlayerClassAccessor.CharacterController.Move 应用；不在蒙皮髋部重复写一份，不开 Animator.applyRootMotion，不调用 Warp、不禁用碰撞。
- 髋部上下起伏仍写到骨架。控制器高度和落地继续由原生重力、地形及碰撞处理；本批不是跳跃控制器或根旋转控制器。MMD 根旋转仍由现有骨架姿势求解，不再给控制器重复旋转。
- 每帧绝对目标为播放起点加当前轨迹，移动量为目标减实际位置；不重复累加采样结果。循环按完整周期累计平移，避免每轮被拉回起点。
- 默认 writeHipTranslation=true 且动作范围包含髋部时启用。显式 false 或不包含髋部的遮罩/骨骼过滤保持不移动控制器。

## 碰撞和取消

- 控制器移动拆成最多 0.1m 的扫掠步，最多 128 步/输出帧。任何非有限值或超过 12.8m 的单帧轨迹断点会停止，绝不转成传送。
- 每步及最终水平目标检查实际到达误差，超过 0.02m 则视为受阻并停止。不会禁用碰撞或推着镜头继续拍摄未到达的位置。
- 动作自己的控制器移动会更新预期位置，原有位置变化保护不会误取消；玩家移动输入、取消、其他原生动作/状态、外部位置变化、UI、场景和角色更换仍按原规则停止。
- 停止恢复骨骼、髋部和表情，玩家留在碰撞允许的实际到达位置，不返回开播点。普通 Unity 动画包没有实现新根位移接口时保留原行为。

## 镜头

镜头维持 0.08 默认比例及动作开始时的固定位置/朝向锚点。没有加入省略位移补偿、逐帧玩家跟随或手部对焦。循环时仅按角色相同的完整周期平移展开原镜头轨迹，单次播放该偏移为零。

归还原生镜头时，把开播前原生镜头的相对位置恢复到角色已到达的位置；这只处理退出动作后的原生视图恢复，不改正在播放的 VMD 镜头。

离线测试覆盖真实 CH4NGE 位移、无重复应用、碰撞边界、取消、外部移动、循环、非有限值/断点拒绝，以及固定镜头锚点和退出恢复。模拟控制器不能替代游戏内墙体、台阶、斜坡与原生重力的运行测试。
